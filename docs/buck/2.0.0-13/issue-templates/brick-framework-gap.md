# Buck 框架能力或缺口

用于提交 Buck 通用能力、SPI、模板、规则或公开组件缺口。业务私有需求不要使用本模板。

## 背景

说明业务场景、触发来源和当前 Buck 版本。

## 现状问题

描述当前缺少什么能力，或者已发布能力哪里不足。

## 期望能力

说明希望 Buck 提供的通用能力、扩展点、配置项、模板或示例。

## 归属判断

- 是否属于 Buck 通用能力：是 / 否。
- 建议归属：core / modules / starters / tools / release bundle / business-agent。
- 业务私有部分应留在业务仓库。

## 边界与禁止事项

- 不能在业务仓库自造平行机制。
- 不能把 validation 示例当成正式业务能力来源。
- 不能绕过 core/module 已有能力。

## 验收标准

- Buck 能力、文档、发布资料包或测试守卫已补齐。
- 业务侧可不读 buck 源码就能采用。
- 如需要发版，说明发布资料包影响。
